# Mozza Italia fonts

These files match the restaurant website's self-hosted fonts:

- `barlow-condensed-bold.ttf`: Barlow Condensed 700, from [`public/fonts/font-1.ttf`](https://github.com/VLR-Technologies/mozza/blob/main/public/fonts/font-1.ttf).
- `manrope-regular.ttf`: Manrope 400, from [`public/fonts/font-3.ttf`](https://github.com/VLR-Technologies/mozza/blob/main/public/fonts/font-3.ttf).
- `manrope-semibold.ttf`: Manrope 600, from [`public/fonts/font-5.ttf`](https://github.com/VLR-Technologies/mozza/blob/main/public/fonts/font-5.ttf).

Both families are licensed under the SIL Open Font License 1.1. The included licenses are from the [Barlow Condensed](https://github.com/google/fonts/blob/main/ofl/barlowcondensed/OFL.txt) and [Manrope](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt) Google Fonts sources. `src/app/fonts.ts` serves them locally through Next.js; no runtime Google Fonts requests are needed.
